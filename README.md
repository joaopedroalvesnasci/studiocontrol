# StudioControl

> Ajuda tatuadores autônomos e pequenos estúdios a organizar clientes, orçamentos e sessões sem depender de conversas espalhadas no WhatsApp, cadernos e planilhas.

**Equipe:** João Pedro Nascimento Alves (RA 214751) e Vinicius Leandro Dos Santos (RA 217315)

**Produção:** https://SUA-URL.vercel.app

## Stack
- Next.js (React + TypeScript) + Tailwind CSS
- Supabase (PostgreSQL, Auth e Storage)
- Vercel (hospedagem)

## Rodando localmente
1. Node.js 20+
2. `npm install`
3. Copie `.env.example` para `.env.local` e preencha as variáveis
4. `npm run dev` e acesse http://localhost:3000
